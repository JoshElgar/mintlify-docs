Visual Components is a 3D manufacturing simulation software that lets you design factory layouts, model material flows, program robots offline, and validate production concepts in a virtual environment before committing to physical changes. Engineers and simulation specialists use it to reduce risk, shorten project timelines, and communicate design intent with animated, data-driven simulations.

## What you can do with Visual Components

Visual Components covers the full range of digital factory tasks in a single application.

<CardGroup cols={2}>
  <Card title="Factory layout design" icon="industry">
    Arrange machines, conveyors, robots, and infrastructure in a 3D space to evaluate floor plan options and optimize space utilization.
  </Card>
  <Card title="Material flow simulation" icon="diagram-project">
    Model how products move through a facility, identify bottlenecks, and calculate cycle times and throughput with built-in statistics.
  </Card>
  <Card title="Robot cell simulation" icon="robot">
    Build realistic robot cells, test reachability, simulate multi-robot coordination, and detect collisions before physical installation.
  </Card>
  <Card title="Offline robot programming" icon="code">
    Write and test robot programs in the simulation, then export them directly to real robot controllers from brands like KUKA, ABB, Fanuc, and YASKAWA.
  </Card>
  <Card title="Virtual commissioning" icon="plug">
    Connect your simulation to real PLC logic via OPC UA or other protocols and validate control software against a virtual machine model.
  </Card>
  <Card title="Production planning" icon="chart-bar">
    Run throughput analyses, calculate cycle times, and produce statistics reports to support investment decisions and production planning.
  </Card>
</CardGroup>

## Editions

Visual Components 5.0 is available in three editions. Each edition builds on the previous one, adding capability for more demanding simulation tasks.

<AccordionGroup>
  <Accordion title="Essentials">
    The entry-level edition covers factory layout design and basic material flow simulation. It includes the eCatalog component library, layout tools, and fundamental simulation controls. Essentials is suitable for engineers who need to create and present factory layouts with animated material flow.
  </Accordion>
  <Accordion title="Professional">
    Professional adds full process modeling capabilities, including product flow statements, transport link configuration, and detailed statistics. It also includes robot simulation — teaching, programming, and reachability analysis — making it the standard choice for simulation engineers working on both material flow and robot applications.
  </Accordion>
  <Accordion title="Premium">
    Premium extends Professional with offline robot programming (OLP) for exporting robot programs to real controllers, virtual commissioning with connectivity plugins (OPC UA, MQTT, PLC interfaces), and interactive VR streaming. Premium targets organizations that use simulation as a direct input to production and commissioning workflows.
  </Accordion>
</AccordionGroup>

<Note>
  All editions share the same interface and file format. Layouts created in a higher edition open in a lower edition, but features not included in that edition will be inactive.
</Note>
