Once you have placed components in a layout and connected them into a working system, you can run a simulation to observe the behavior, collect statistics, and validate your design. Visual Components simulates component behaviors, material flow, robot programs, and inter-component signaling all at once, giving you a dynamic, time-accurate view of your factory system.

## Simulation controls

The simulation controls are located in the **Simulation** tab of the ribbon toolbar. You can also access play/pause/stop through keyboard shortcuts for faster control during work.

| Control | Shortcut | Description |
|---|---|---|
| **Play** | **F5** | Starts or resumes the simulation from the current time. |
| **Pause** | **F6** | Pauses the simulation at the current state. Components freeze in place. |
| **Stop / Reset** | **F7** | Stops the simulation and resets all components to their initial state. |
| **Step** | — | Advances the simulation by a single time step (useful for debugging). |

<Note>
  When you stop a simulation, all components return to their starting positions and product objects generated during the simulation are removed. The layout itself is not affected — only the simulation state resets.
</Note>

## Simulation speed

By default, Visual Components runs the simulation at real-time speed (1×). You can increase the speed to fast-forward through repetitive cycles or decrease it to observe fast-moving processes in detail.

Adjust the **Simulation Speed** slider in the **Simulation** ribbon tab:

- **1×** — real-time, matches actual wall-clock time.
- **2× to 100×** — accelerated time. The simulation runs faster than real-time, which is useful for collecting steady-state statistics on long production runs.
- **0.1× to 0.5×** — slowed-down time. Useful for observing robot motion or product handling in detail.

<Tip>
  Run at 10× or faster to collect statistics efficiently. Most simulations need at least several hundred cycles to reach a stable throughput rate. Use the output panel to watch for startup warnings before reading statistics.
</Tip>

## The simulation timeline

The simulation timeline at the bottom of the 3D world shows the current simulation time (in seconds by default). As the simulation runs, the timer counts up. You can scrub the timeline backward and forward when the simulation is paused to review what happened at a specific moment.

## Statistics dashboard

The statistics dashboard collects and displays performance data as the simulation runs. Open it from **Simulation → Statistics** in the ribbon.

Key metrics shown in the dashboard include:

- **Throughput** — the number of products completed per time unit (for example, parts per hour).
- **Cycle time** — the time between consecutive product completions at a defined sink.
- **Resource utilization** — the percentage of time each machine, conveyor, or robot is active versus idle or blocked.
- **Buffer levels** — the number of products waiting in queues at each process resource.
- **Bottleneck identification** — resources with high utilization or long queue times that limit overall throughput.

The statistics panel updates live as the simulation runs. You can export the data to a spreadsheet for further analysis using **Statistics → Export to CSV**.

## Output panel

The output panel (docked at the bottom of the screen) shows messages generated by the simulation in real time. Messages come from three sources:

- **Component behaviors** — built-in status messages such as "Product created", "Robot program started", or "Conveyor blocked".
- **Python scripts** — custom messages written by scripted component behaviors using `vcScript.log()`.
- **System warnings and errors** — notifications about configuration problems, connection errors, or simulation issues.

Filter the output by message type using the **Info**, **Warning**, and **Error** toggle buttons at the top of the panel. Use the search field to find specific messages.

## Recording a simulation

You can record your simulation as a video file to share results with stakeholders.

<Steps>
  <Step title="Open recording settings">
    Go to **Simulation → Record** in the ribbon toolbar. The recording settings panel appears.
  </Step>
  <Step title="Configure resolution and frame rate">
    Set the output resolution (for example, 1920×1080) and frame rate (typically 30 fps for smooth playback). Higher resolution and frame rate produce larger files.
  </Step>
  <Step title="Start recording">
    Click **Start Recording**, then press **F5** to start the simulation. Visual Components captures every rendered frame during the simulation run.
  </Step>
  <Step title="Stop and save">
    Press **F7** to stop the simulation, then click **Stop Recording**. Choose a file name and location to save the output as an `.avi` or `.mp4` file.
  </Step>
</Steps>

<Warning>
  Recording at high resolution significantly increases CPU and disk usage. Close other applications before recording long simulations to maintain smooth capture.
</Warning>

## Cycle time calculator

The cycle time calculator is a tool that estimates the cycle time of a robot program or process operation before running a full simulation. Access it from **Simulation → Cycle Time Calculator**. Select the robot or resource and the program to analyze. The calculator computes the theoretical cycle time based on motion parameters and statement durations, giving you a quick estimate without a full simulation run.
