Visual Components uses a software license to control access to the application and its features. Before you can use the software past the initial evaluation period, you need an active license. This page explains the license types available, how they differ, and how to manage licenses through the Visual Components license portal.

## License types

Visual Components offers two fundamental license types that differ in how the license is tied to a machine.

<Tabs>
  <Tab title="Standalone (node-locked)">
    A standalone license is locked to a specific physical machine identified by its hardware fingerprint. The license activates on one computer and can only be used on that computer. It does not require a network connection to run the software — once activated, Visual Components works fully offline.

    **Best for:** Individual engineers with a dedicated workstation, air-gapped environments, or situations where reliable network access to a license server is not available.

    **Transferring a standalone license:** You can deactivate the license from the current machine and activate it on a different machine. See [Deactivate Your Visual Components License](/getting-started/license-deactivation) and [Activate Your Visual Components License](/getting-started/license-activation) for the step-by-step process.
  </Tab>
  <Tab title="Network (floating)">
    A network license (also called a floating license) is served from a license server on your local network. A pool of license seats is checked out by users when they launch Visual Components and returned to the pool when they close the application. Multiple users share the same pool — the number of simultaneous users is limited by the seat count.

    **Best for:** Teams where not all users need access at the same time, organizations with a managed IT environment, or companies that want centralized license administration.

    **Requirements:** A machine running the Visual Components License Server software must be accessible on the local network. Clients connect to this server at launch. The client machine does not need an internet connection, but must have network access to the license server.
  </Tab>
</Tabs>

## Editions and included features

Your license key determines which edition — Essentials, Professional, or Premium — you are licensed for. See the [Overview](/getting-started/overview) page for a full description of what each edition includes.

<AccordionGroup>
  <Accordion title="Essentials">
    Covers factory layout design, eCatalog access, basic material flow visualization, and simulation playback. Suitable for layout engineers and designers who need to create and present factory concepts.
  </Accordion>
  <Accordion title="Professional">
    Adds full process modeling with product flow, transport links, and statistics, plus robot simulation with path teaching and programming. The standard choice for simulation engineers working on production planning and robot applications.
  </Accordion>
  <Accordion title="Premium">
    Extends Professional with offline robot programming (OLP) for real robot brands, virtual commissioning via connectivity plugins, and interactive VR streaming. The choice for organizations that use simulation as a direct production and commissioning tool.
  </Accordion>
</AccordionGroup>

## Evaluation (trial) licenses

If you do not yet have a purchased license, you can request a time-limited evaluation license from Visual Components. An evaluation license gives you full access to the Premium edition for a defined trial period (typically 30 days), so you can evaluate all features before purchasing.

To request an evaluation license:

1. Go to the Visual Components website and fill in the trial request form.
2. Visual Components sends you a product key by email.
3. Launch the application and enter the product key in the license activation wizard.

<Note>
  Layouts and components created during an evaluation period are fully compatible with purchased licenses. Your work is not lost when you transition from evaluation to a purchased license.
</Note>

When your evaluation period ends and you have purchased a license, you can upgrade the evaluation license to a full license without deactivating. See [Activate Your Visual Components License](/getting-started/license-activation) for the upgrade process.

## The license portal

The Visual Components license portal at [license.visualcomponents.net](https://license.visualcomponents.net) is where you manage all licenses associated with your organization's account. Through the portal you can:

- View all purchased licenses and their activation status.
- Deactivate a license remotely if the machine it was activated on is no longer accessible.
- Download license files for manual (offline) activation.
- View license expiry dates and maintenance periods.
- Request additional seats or upgrade an edition.

Sign in with your Visual Components account credentials to access the portal. Contact your Visual Components reseller or the support team if you do not have portal access.

## License maintenance and renewal

Most Visual Components licenses include an annual maintenance period that covers:

- Access to new software versions released during the maintenance period.
- Access to the online eCatalog component library.
- Technical support entitlement.

When the maintenance period expires, you can continue using the version of the software you have, but you lose access to new versions and updated catalog content. Renew maintenance through your reseller or the Visual Components sales team.
