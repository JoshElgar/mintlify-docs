Visual Components Academy is the official learning hub for Visual Components software — a 3D manufacturing simulation platform used to design factory layouts, program robots offline, model material flows, and validate production concepts before physical deployment. Whether you are new to the software or looking to master advanced features like Python scripting or virtual commissioning, this documentation guides you step by step.

## Quick start

<Steps>
  <Step title="Install Visual Components">
    Download and install the software from the [Visual Components downloads page](https://www.visualcomponents.com/downloads/). Version 5.0 or higher is recommended.
  </Step>
  <Step title="Activate your license">
    Launch the application and follow the license activation wizard. See [License Activation](/getting-started/license-activation) for manual activation steps.
  </Step>
  <Step title="Learn the interface">
    Familiarize yourself with the 3D world, ribbon toolbar, eCatalog panel, and properties panel. See [Interface Overview](/getting-started/interface).
  </Step>
  <Step title="Build your first layout">
    Use the eCatalog to drag pre-built components into the 3D world and run your first simulation. See [Layouts](/getting-started/layouts).
  </Step>
</Steps>
